The seven confirmed findings and three design recommendations have been addressed in the app. The warm visual identity is retained, with a smaller phone banner, clearer language, accessible controls and more useful screen structure.

What changed

AuditImplementation
A01Guests cannot use Join: the button spins indefinitely
Join and circle chat now require a real, non-null pending account scope. Guest actions remain available; account-change and stale-response safeguards are retained.
A02Selected tabs and filters are visual only in the web preview
A shared adapter preserves native accessibility state and supplies web pressed, selected, current, checked, busy and disabled attributes. Applied across navigation, filters, toggles and operation controls.
A03Most visual screen titles are not semantic headings
Shared headings provide native header roles and web heading levels. Page titles, section titles, empty states and dialog titles use a logical hierarchy.
A04Browser pages have no human-readable document title
Every route has a browser title. Public circle and person pages use the loaded name; composer modes and sign-in recovery have contextual titles.
A05Dialogs lack an accessible name
All seven modal declarations have accessible names. Comments and profile close buttons have contextual labels. Sign-in and comments focus return was checked in the browser.
A06The desktop search advertises an unimplemented shortcut
Ctrl+K and Command+K open Discover and focus its search. Invoking the shortcut on Discover focuses the existing input. Typing in editable fields is protected; the badge matches the platform.
A07Single-item counts use plural copy
Shared count helpers fix singular member, moment, saved moment and follower wording, including loaded-collection copy.
R01Bring actual communities higher on small phones
Phones use a compact 96-pixel banner with shorter copy and tighter spacing. The larger banner is retained for wider layouts.
R02Use consistent names for communities and content
The main directory is called Circles. Owned collections remain Your circles. Visible composer, discovery and moment-action wording uses Moments consistently.
R03Replace engineering language in the live lobby with user guidance
Live setup guidance now explains permissions, supported apps and connection recovery in plain language.

Additional screen polish

  • Discover combines each person’s avatar and name into one profile target, reducing duplicate keyboard stops.
  • Unconfigured circle Home content becomes one welcoming visitor panel with an Explore moments action. Managers retain their setup prompts.
  • Update detail titles and the Mark as read action can wrap at narrow widths. Secondary empty states preserve the page-heading hierarchy.

Full-suite results: 975 pass, 18 fail

The following tests and their corresponding tooling are unchanged by the design patch. Failures include Linux-only executable assumptions, Windows symlink/permission behaviour, checkout line-ending/hash expectations and dependency/tool invocation checks. They remain visible for follow-up; no security assertions were relaxed.

  • circle-home-e2e-safety.test.ts
    • strips credentials and fails closed on stop/partial-start failures
  • container-source-trigger.test.ts
    • runs for API and dependency changes as well as manual invocation
  • coturn-operations.test.ts
    • has syntax-clean helpers and refuses absent host prerequisites in default dry-run mode
    • requires TLS files and rejects host mutation unless root explicitly acknowledges --apply
    • renders a protected transient config without writing or logging the synthetic secret elsewhere
  • email-identity.test.ts
    • keeps schema/table private, owner-postgres, FORCE RLS, and only runtime SELECT/INSERT policies
  • oauth-audit-output-paths.test.ts
    • rejects a symlinked output parent pointing inside the actual Git tree
    • uses the Git root even when project-dir is a source subdirectory
  • oauth-pending-state.test.ts
    • keeps the migration private, RLS-enforced, and limited to the existing runtime role
  • origin-binding.test.ts
    • rejects an unbound continuity export before opening the bearer file
  • recover-api.test.ts
    • reports an invalid trusted auth-file live generation as incomplete without issuing live.signals
  • recovery-continuity.test.ts
    • encrypts a complete synthetic package to the approved public recipient and leaves no plaintext output
  • sec27-database-hardening.test.ts
    • keeps the bootstrap role proposal unapplied, narrowly scoped, and free of arbitrary role routing
  • sec27-dependency-consumers.test.ts
    • SEC-030 keeps the Expo flat configuration executable on the final ESLint 9 patch
  • sec27-operations-remediation.test.ts
    • locks the applied initial operations migration while making atomic checksum transport future-only
  • source-formatting.test.ts
    • refuses symlinks and parent-directory escapes
  • supabase-security-audit.test.ts
    • accepts only new private outputs outside the project Git tree and creates 0600 files exclusively
    • rejects a project subdirectory and every symlinked output parent without writing a report

Remaining verification

  • Authenticated populated flows require original authorised login configuration. Email sign-in remains disabled in this environment.
  • Physical iOS/Android devices, native camera/microphone, real broadcasts, large system fonts, VoiceOver and TalkBack remain unverified.
  • Authenticated editors, populated messages, moderation actions, update read states and preferences, onboarding steps, and active live controls need a real approved session.

No memberships, messages, moments, reports, preferences or broadcasts were created or modified during browser verification. No database schema or authentication configuration changes were made. The original audit remains available separately.
