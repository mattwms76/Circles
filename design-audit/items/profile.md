# Profile — own profile and editor

**Scope.** Read-only review of `components/profile-screen.tsx` and `app/(tabs)/profile.tsx`, with only the shared `circles-ui.tsx` and `app-shell.tsx` primitives needed for layout/accessibility context. Screenshots are clean signed-out gates at 320×740, 390×844, 768×1024, and 1440×1000. Therefore the signed-in own-profile, edit modal, moderation, and live-session states below are **source-reviewed risks, not visually verified**. Coral/cream/sage identity is coherent in the supplied captures.

## Cross-screen notes

- **Visually confirmed gate:** all four supplied screenshots show consistent 20px mobile/tablet content gutters, a clean header rule, centered coral empty-state icon/title/action, and no visible horizontal overflow or header/tab occlusion. The 320px gate wraps its explanatory copy cleanly; the 390px version has more comfortable line length. The 768px gate remains centered with ample whitespace.
- **Wide shell:** the 1440px capture switches to the 900px `wide` shell: 226px navigation rail, 296px community rail, and a 30px content padding. The profile content is geometrically aligned and the coral/cream/sage system remains consistent. This is a shell-level layout observation, not a defect in `app/(tabs)/profile.tsx` (which is only a re-export).
- **Safe areas/navigation:** the mobile captures show the bottom navigation clear of the signed-out content; no visible overlap or clipped gate was found. Source review did not expose editor-specific keyboard/safe-area behavior, hence the keyboard issue remains a risk rather than a visual claim.
- **Conditional modes:** `personId` switches own vs other-person profile; `Saved` is only rendered for own profiles; follow/message use `requireAuth`; missing-profile and loading/empty/feed states are source-reviewed. Moderation/post actions are delegated to `PostCard` and were not expanded because they are outside the assigned files. Live-session content does not exist per brief; no live visual claim is made.
- **No source changes or runtime/test execution performed.**
