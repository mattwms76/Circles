# Compose — design audit

**Scope:** `/create` Post / Circle / Go live composer, signed-out captures only at 320×740, 390×844, 768×1024, and 1440×1000. Authenticated form states, live-session behavior, keyboard behavior, media editing, and upload/error overlays were **source-reviewed, not visually verified** because the captures are gated and there are no active sessions. Coral/cream/sage identity is consistent and no screenshot shows clipping, overlap, or horizontal document overflow in the signed-out state.

## Covered states and risks

- **Post:** signed-out gate visually confirmed at all four breakpoints; authenticated text/media form and photo/video picker are source-reviewed. Asset preview is a fixed 210px `cover` frame (`create.tsx:326-335`); change-photo affordance exists, but crop/remove/edit overlays were not captured and are not visually verified.
- **Circle:** title/name, description, category wrapping, privacy choices, cover-photo picker, and public/private creation paths are source-reviewed. The privacy row is the key breakpoint risk above.
- **Go live:** title/description and sage camera/microphone notice are source-reviewed; Expo Go guard and live-session transition are source-reviewed, not visually verified. No active conversation/live session or moderation overlay existed to inspect.
- **Editing/overlays:** this file implements creation rather than editing existing posts/circles; only the selected-media “Change photo/video” state is present. No edit modal, crop overlay, error toast, or keyboard overlay was captured.
- **Gutters/safe areas:** signed-out content uses consistent 24px phone gutters and a centered 572px inner column at tablet/wide; header uses 20px padding plus `insets.top` (`create.tsx:140-155`). No fixed header/tab occlusion or document horizontal overflow is visually confirmed. The 24px phone gutter is slightly wider than the 16–20px goal but remains balanced and intentional.
