# Circles — All-Screen Design Audit

> **Versioned audit archive:** this report describes the immutable pre-Activity-Inbox baseline, not a fresh audit of the current app. Activity Inbox is now implemented and separately validated. Original line references and historical wording are retained for traceability. Screenshots, raw browser observations and other local evidence cited below are intentionally not published in this repository; this archive does not include private content or upgrade source risks to native/runtime proof. Selection of a fix batch is tracked separately in `docs/next-development-batch.md`.

**Audit date:** 2026-10-23
**Immutable-baseline context:** `c22ebc35c74023242a87b536a875b1c74b940947` (task-supplied `source-sha.txt`; the source export has no `.git`, so this was not Git-resolved)
**Deliverable mode:** synthesis only — **no application fixes, source edits, tests, server work, or re-audit were performed.**
**Scope:** supplied static per-screen audits plus the supplied signed-out rendered observation. The in-progress **Activity Inbox / Updates** implementation is expressly excluded from the old-baseline findings and remains for its separate integration review.

## Executive priorities

There are **48 deduplicated issues**: **30 Medium**, **18 Low**, and **0 High**. “Moderate” from a source report is normalized to **Medium**; “Minor” is normalized to **Low**. Counts include source-confirmed defects and clearly marked conditional source risks, but **exclude pure coverage gaps** and intentional design choices.

1. **Repair shared primitives first.** The `Button` loading state removes its spoken name and does not expose busy/disabled state; `Input` visually labels fields without attaching a programmatic name; remote-media rendering lacks an error fallback; ordinary `C.muted` body copy is under contrast. These repeat across the product.
2. **Protect responsive/safe-area layout.** Make the AppShell header capable of reflowing at large text, apply insets on all relevant shell edges, and resolve route-local fixed/nonwrapping layouts (Circles hero, messages filters, profile stats, composer modes, Circle intro, OAuth recovery view).
3. **Make navigation and async controls reliably operable.** Add destination names to image-only controls, restore 44 pt targets, disable/busy-bind operations while requests are pending, and disable blank chat sends.
4. **Address contrast where text communicates state or information.** In addition to muted body text, correct semantic action/status pairs (white on coral, coral on soft, green on background) and Home’s terminal disclosure.
5. **Keep screen-local fixes scoped.** Resolve Circle membership filtering, search-limit mismatches, person-route return navigation, composer mutation coherence, Theme Lab’s nonfunctional Dark preview, and the rendered Home Like hit-area finding without treating aesthetics or intentionally hidden chrome as defects.

## Severity, evidence, and terminology

- **Confirmed** means the source establishes the defect mechanism, or the rendered observation directly measured it. It does **not** claim native runtime proof unless marked **Rendered**.
- **Conditional source risk** means the code/data path is valid but the triggering device state, failed URI, long value, or font scale was not executed.
- **Exact source references** below are the supplied file-and-line evidence, not fresh source inspection.
- Existing **hidden scroll indicators**, the intentional absence of a mobile Chats tab (Messages remains in the labelled header action), warm editorial styling, and deliberate cover crops are **not bugs** in this audit.
