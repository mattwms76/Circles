# Live profile indicator

A separate pulsing live stroke and LIVE chip now accompany user avatars whose broadcast is ready, fresh and visible to the current viewer. The existing story border, avatar image/fallback, frame dimensions and press destinations are unchanged. Story avatars use a4-point live-overlay inset, so the pulse is an inner layer rather than a replacement border.

The shared UserAvatar wrapper registers only a source-provided positive numeric person ID. Circle/group images and conversation/live-chat thumbnails that lack such an ID retain the original Avatar; no identity is inferred from a name, URL or image. Status is batched in64-ID requests with a512-mounted-person/eight-request ceiling, not polled individually. Arbitrarily larger simultaneously mounted feeds are outside verified coverage.

The existing live.list API has optional hostIds/readyOnly/viewerScope inputs, preserving old callers.
