Practical limits

The browser is a simulated prototype. A Hermes export is not a signed native device test. Real iOS/Android keyboards, Dynamic Type, VoiceOver/TalkBack, safe-area variants and physical camera/audio behavior still need device acceptance. Existing external service configuration remains a separate release prerequisite; this layout pass does not enable missing Agora, push or store credentials.

Preview appearance and text size were restored to System/100%, temporary viewport overrides were cleared, and no test message was sent. Local screenshots and browser measurements are retained under the ignored .tools/layout-screenshots/ directory. No backend schema/configuration was changed and no GitHub commit/push was performed for this layout pass.
